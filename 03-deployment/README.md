# Module 3 — Test, Containerize, and Deploy an AI-Assisted App

Course-following notes and planning for Module 3 of DataTalksClub's AI Dev Tools
Zoomcamp (2026 cohort). This folder intentionally holds no application code:

- `module-03-lessons.md` — technique lessons distilled from the module's article
  and workshop video.
- `agent-relay-reports.md` — the build/verification log for every homework
  question, question by question.

**The graded homework itself — Agent Relay — lives in a separate, standalone
repo:** [Sanjomwa/agent-relay](https://github.com/Sanjomwa/agent-relay)
(forked from [alexeygrigorev/agent-relay](https://github.com/alexeygrigorev/agent-relay)).
That's where the Dockerfile, Docker Compose setup, Kubernetes manifests, and
CI/CD workflow actually live — not here, and not under `homework/module_03/`
in this repo either (see that folder's own README). Submitted answers for the
six graded questions and the reflection are recorded in
`homework/module_03/_docs/homework-answers.md`.
