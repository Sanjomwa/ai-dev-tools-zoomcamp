# Task Template

Every groomed issue body follows this structure.

## Goal

One sentence: what's true once this is done. Not a description of the work.

## Acceptance Criteria

- Checkable, one per line. Each one answerable yes/no by looking at the running app or the code.

## Out of Scope

- What this issue deliberately does not cover, especially anything a reader might assume is included.

## Constraints

- Stack choices, existing models/views this must build on, conventions from `AGENTS.md`.
